## 背景

模型接口响应中的标准 usage 当前通常是上游用量，而平台启用计量放大后以 billable usage 计费，调用方无法使用响应中的数据核对平台计费用量。

## 变更

- 对完整成功请求，在标准模型响应 usage 中返回平台计费用量，覆盖 OpenAI、Anthropic、Gemini 原生协议与兼容转换，包括非流式、流式和 Responses WebSocket。
- 保留内部上游原始用量及其管理员审计用途，响应、日志和计费共享同一次请求的计量策略和处理口径。
- 继续使用现有缓存分类、计量放大与取整规则；Embeddings、预估接口、按图或按次费用遵循现有计费规则。
- 文档明确上下文 token 语义变化和中断、缺失用量、异步结算的限制。

## 影响

影响模型响应的 usage 标准字段及依赖它们的客户端；不改变上游请求、已有计费价格策略或历史账单。

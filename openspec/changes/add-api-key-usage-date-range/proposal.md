## Why

API 密钥页当前固定展示“今日”和“近30天”用量，用户无法按自己关心的账期或排查窗口查看单个密钥的消费汇总。使用记录页已经有时间范围选择器，API 密钥页应复用同类交互，让列表用量汇总与用户选择的时间范围一致。

## What Changes

- 在 API 密钥页筛选区增加时间范围选择器，默认选择近 30 天。
- 用户切换时间范围后，API 密钥列表的用量汇总重新按该范围统计并刷新展示。
- 用量列第二行的“近30天”文案随用户选择变化，展示当前统计范围；“今日”用量保持现有逻辑和含义不变。
- 扩展 API 密钥用量汇总接口，使其可接收可选的开始/结束日期范围。
- 不引入新的计费口径、倍率展示或额外依赖。

## Capabilities

### New Capabilities
- `api-key-usage-date-range`: 普通用户在 API 密钥页选择时间范围，并按该范围查看每个 API 密钥的消费汇总。

### Modified Capabilities

None.

## Impact

- 前端 API 密钥页：筛选区、用量列文案、用量汇总请求参数和加载刷新逻辑。
- 前端通用时间范围组件：复用现有使用记录页的 DateRangePicker 行为，不新增选择器实现。
- 用户侧 API：API 密钥批量用量汇总接口增加可选日期范围参数。
- 后端用量服务：按指定日期范围聚合范围用量，今日用量仍按当天独立统计。
- 测试：覆盖默认近 30 天、切换时间范围、接口参数传递和今日用量不受范围影响。

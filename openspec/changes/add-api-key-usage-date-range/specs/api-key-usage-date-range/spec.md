## ADDED Requirements

### Requirement: API 密钥页支持用量时间范围
系统 SHALL 在普通用户 API 密钥页提供时间范围选择器，用于控制每个 API 密钥用量列中的范围消费汇总。

#### Scenario: 默认展示近 30 天范围
- **WHEN** 普通用户打开 API 密钥页
- **THEN** 时间范围选择器默认选中近 30 天
- **THEN** 系统按近 30 天统计每个 API 密钥的范围消费
- **THEN** 用量列的范围消费标签展示近 30 天

#### Scenario: 用户选择预设时间范围
- **WHEN** 普通用户在 API 密钥页选择一个时间范围预设
- **THEN** 系统使用该预设对应的开始日期和结束日期重新请求 API 密钥用量汇总
- **THEN** 用量列的范围消费金额按所选范围展示
- **THEN** 用量列的范围消费标签展示所选预设名称

#### Scenario: 用户选择自定义时间范围
- **WHEN** 普通用户在 API 密钥页选择自定义开始日期和结束日期并应用
- **THEN** 系统使用该开始日期和结束日期重新请求 API 密钥用量汇总
- **THEN** 用量列的范围消费金额按自定义范围展示
- **THEN** 用量列的范围消费标签展示该自定义日期范围

#### Scenario: 今日用量不受范围影响
- **WHEN** 普通用户选择的时间范围不包含今天
- **THEN** 用量列的今日消费仍按今天独立统计
- **THEN** 今日消费不得因为所选范围不包含今天而清零或隐藏

### Requirement: API 密钥用量汇总接口支持可选日期范围
系统 SHALL 允许 API 密钥批量用量汇总接口接收可选日期范围，并按该范围返回每个 API 密钥的范围消费汇总。

#### Scenario: 请求包含日期范围
- **WHEN** 普通用户请求 API 密钥批量用量汇总接口并提供开始日期和结束日期
- **THEN** 系统只统计该用户拥有的 API 密钥
- **THEN** `total_actual_cost` 按包含开始日期和结束日期的自然日范围统计
- **THEN** `today_actual_cost` 继续按今天独立统计

#### Scenario: 请求未包含日期范围
- **WHEN** 普通用户请求 API 密钥批量用量汇总接口但未提供日期范围
- **THEN** 系统保持现有默认近 30 天范围统计
- **THEN** 响应结构保持兼容

#### Scenario: 请求包含无效日期范围
- **WHEN** 普通用户请求 API 密钥批量用量汇总接口并提供无效日期格式或结束日期早于开始日期
- **THEN** 系统拒绝请求并返回请求参数错误
- **THEN** 系统不得返回其他用户的 API 密钥用量
